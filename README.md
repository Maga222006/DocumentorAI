# Documentor AI

An interactive learning platform that transforms PDF documents into personalized learning experiences. Upload documents, get AI-generated summaries, take adaptive quizzes, and chat with an AI tutor for deeper understanding.

## Backend

This frontend connects to the [TutorAgent](https://github.com/Maga222006/TutorAgent) backend API.

## Tech Stack

- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui

## Development

```sh
npm install
npm run dev
```
